About Shorts Upload

Shorts Upload is a small personal tool of one creator, the Twitch streamer Musaabi. It uploads short clips from Musaabi’s own Twitch live streams as YouTube Shorts to Musaabi’s own YouTube channels. To do this, it uses YouTube API Services (the YouTube Data API v3).

Not a public service. Shorts Upload is not offered to anyone else: there is no download, no sign-up, no user accounts and no advertising. Its only user is Musaabi, and only Google accounts that belong to Musaabi are connected to it.

Privacy Policy Terms of Use

How it works

  • Shorts Upload is a command-line program that runs only on Musaabi’s own Windows PC. There is no server and no web or mobile app.
  • Short vertical clips are made from Musaabi’s own stream recordings. For each clip folder, Musaabi prepares a text file with the title, description, hashtags and tags for its clips and a score for each clip; the clips with the highest score are uploaded first. A clip without a prepared title and description is never uploaded.
  • Windows Task Scheduler starts the tool three times a day. Each run uploads at most one clip per channel, so a channel receives at most three new videos per day.
  • Shorts Upload is designed so that each clip is uploaded only once, to one channel: every successful upload is recorded, and a recorded clip is never uploaded again.
  • Each upload uses the visibility (public, unlisted or private) and the “made for kids” declaration (yes or no) that Musaabi set in the tool’s settings and confirmed when the channel was connected.
  • Google accounts are connected through Google’s own sign-in page in the web browser. Shorts Upload never sees or stores a Google password.

Google and YouTube data it uses

For each connected Google account, Shorts Upload asks for the following permissions and uses each one only for the purpose shown:

https://www.googleapis.com/auth/youtube.upload
Upload videos to the connected YouTube channel.
https://www.googleapis.com/auth/youtube.readonly
Read the name of the connected channel, to confirm which channel receives the uploads.
https://www.googleapis.com/auth/userinfo.email openid
When an account is connected, read its email address, to confirm that the intended Google account was used.

Everything Shorts Upload stores stays on Musaabi’s PC. Data is sent only to Google and YouTube, as far as these functions need it. It is never sold, never shared with anyone else, never used for advertising and never used to train AI models. The Privacy Policy explains the details.

Limited Use: Shorts Upload’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting and revoking access

A channel can be disconnected at any time with the command upload_shorts.py abmelden <account>. It revokes Shorts Upload’s access at Google, deletes the stored sign-in token and deletes the YouTube data stored for that account. Access can also be removed on Google’s security settings page: https://security.google.com/settings/security/permissions

Über Shorts Upload

Shorts Upload ist ein kleines privates Werkzeug eines einzelnen Creators, des Twitch-Streamers Musaabi. Es lädt kurze Clips aus Musaabis eigenen Twitch-Livestreams als YouTube Shorts auf Musaabis eigene YouTube-Kanäle hoch. Dafür nutzt es die YouTube API Services (die YouTube Data API v3).

Kein öffentlicher Dienst. Shorts Upload wird niemandem sonst angeboten: Es gibt keinen Download, keine Registrierung, keine Benutzerkonten und keine Werbung. Einziger Nutzer ist Musaabi, und verbunden werden nur Google-Konten, die Musaabi gehören.

Datenschutzerklärung Nutzungsbedingungen

So funktioniert es

  • Shorts Upload ist ein Kommandozeilenprogramm und läuft nur auf Musaabis eigenem Windows-PC. Es gibt keinen Server und keine Web- oder Handy-App.
  • Aus Musaabis eigenen Stream-Aufnahmen entstehen kurze Clips im Hochformat. Für jeden Clip-Ordner bereitet Musaabi eine Textdatei mit Titel, Beschreibung, Hashtags und Tags für seine Clips und einem Score je Clip vor; die Clips mit dem höchsten Score werden zuerst hochgeladen. Ein Clip ohne vorbereiteten Titel und vorbereitete Beschreibung wird nie hochgeladen.
  • Die Windows-Aufgabenplanung startet das Programm dreimal am Tag. Jeder Lauf lädt höchstens einen Clip pro Kanal hoch – ein Kanal bekommt also höchstens drei neue Videos pro Tag.
  • Shorts Upload ist so gebaut, dass jeder Clip nur einmal und nur auf einen Kanal hochgeladen wird: Jeder erfolgreiche Upload wird vermerkt, und ein vermerkter Clip wird nie erneut hochgeladen.
  • Jeder Upload verwendet die Sichtbarkeit (öffentlich, nicht gelistet oder privat) und die Angabe „speziell für Kinder“ (ja oder nein), die Musaabi in den Einstellungen festgelegt und beim Verbinden des Kanals bestätigt hat.
  • Google-Konten werden über die Anmeldeseite von Google im Webbrowser verbunden. Shorts Upload sieht und speichert keine Google-Passwörter.

Welche Google- und YouTube-Daten es nutzt

Für jedes verbundene Google-Konto fragt Shorts Upload die folgenden Berechtigungen an und nutzt jede nur für den genannten Zweck:

https://www.googleapis.com/auth/youtube.upload
Videos auf den verbundenen YouTube-Kanal hochladen.
https://www.googleapis.com/auth/youtube.readonly
Den Namen des verbundenen Kanals lesen, um zu bestätigen, welcher Kanal die Uploads erhält.
https://www.googleapis.com/auth/userinfo.email openid
Beim Verbinden eines Kontos dessen E-Mail-Adresse lesen, um zu bestätigen, dass das vorgesehene Google-Konto verwendet wurde.

Alles, was Shorts Upload speichert, bleibt auf Musaabis PC. Daten gehen nur an Google und YouTube, soweit diese Funktionen es erfordern. Sie werden nie verkauft, nie an andere weitergegeben, nie für Werbung genutzt und nie zum Training von KI-Modellen verwendet. Einzelheiten stehen in der Datenschutzerklärung.

Eingeschränkte Nutzung (Limited Use): Die Nutzung und Weitergabe von Informationen, die Shorts Upload über Google-APIs erhält, entspricht der Google API Services User Data Policy einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use requirements).

Verbindung trennen und Zugriff widerrufen

Ein Kanal lässt sich jederzeit mit dem Befehl upload_shorts.py abmelden <konto> trennen. Der Befehl widerruft den Zugriff von Shorts Upload bei Google, löscht das gespeicherte Anmelde-Token und löscht die für dieses Konto gespeicherten YouTube-Daten. Außerdem lässt sich der Zugriff auf der Google-Seite für Sicherheitseinstellungen entfernen: https://security.google.com/settings/security/permissions
